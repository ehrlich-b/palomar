# Palomar formalizations

## Antihydra

The Antihydra entry proves that no semilinear inductive safety invariant
exists for the shifted recurrence from `(8, 0)`. It also derives the
Presburger-definable corollary.

The Palomar project path is `antihydra` and the Comparator configuration
is `antihydra/comparator.json`.
[Read the proof overview and build instructions](antihydra/README.md).
